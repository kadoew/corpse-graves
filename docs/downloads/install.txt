========================================
Corpse Graves 1.1.0 — Minecraft 26.3 / Fabric
تعليمات التثبيت والتشغيل
========================================

【المتطلبات】
- Minecraft Java Edition 26.3
- Fabric Loader 0.19.3 أو أحدث (تم اختبار 0.19.5 و0.20.1 مع جار 26.3 النهائي)
- Fabric API 0.165.0+26.3  (الملف المرفق fabric-api-0.165.0+26.3.jar)
- Java 25 (يطلبها Minecraft 26.3 نفسه)

【لماذا ظهر الخطأ السابق؟】
1) "requires version 0.20.0 or later of fabricloader"
   كان المود القديم يطلب Loader 0.20.0. تم إصلاح ذلك في 1.1.0؛ الحد الأدنى الآن 0.19.0
   وFabric API نفسه يحتاج 0.19.3. لذلك Loader 0.19.5 يعمل الآن.
2) "fabric-api is missing"
   يجب تثبيت Fabric API أيضاً؛ المود لا يعمل بدونه.
   لا تضع المود وحده في مجلد mods.

【التثبيت】
1) احذف أي نسخة قديمة من المود من مجلد mods، خصوصاً:
   corpsegraves-1.0.0.jar
   (وجود نسختين بنفس معرف المود يسبب خطأ).
2) انسخ الملفين التاليين إلى مجلد mods:
   - corpsegraves-1.1.0.jar
   - fabric-api-0.165.0+26.3.jar
3) شغّل اللعبة عبر Fabric Loader 26.3.
4) للتشغيل على سيرفر: ضع نفس الملفين في مجلد mods على السيرفر أيضاً.
   - يمكن تشغيل المود على السيرفر فقط: اللاعبون بدون المود يرون القبر والهولوغرام
     (لأنهما كيانات فانيلا) ويستطيعون أخذ كل الأغراض بنقرة.
   - الواجهة الرسومية (GUI) والأزرار تحتاج المود على جهاز اللاعب.
   - رفع سكين اللاعب المخصص في وضع offline يحتاج أيضاً المود على العميل.

【الإعدادات】
- يُنشأ الملف تلقائياً على السيرفر في:
  config/corpsegraves.json
  وعلى اللعبة المفردة/العميل في:
  .minecraft/config/corpsegraves.json
- الملف المرفق corpsegraves.sample.json هو نسخة افتراضية كاملة يمكنك نسخها فوق الملف.
- بعد أي تعديل نفّذ:
  /corpsegraves reload

أهم الخيارات:
  despawnSeconds = 3600       مدة بقاء القبر (60 دقيقة)، -1 = لا يختفي
  unlockSeconds  = 1800       مدة حماية القبر (30 دقيقة). 0 = متاح للجميع فوراً
                              -1 = محمي لصاحبه للأبد
  xpRecoveryPercent = 50      نسبة الخبرة المستعادة (الافتراضي الآن 50%)
  onlyOwner... (حُذف)          استخدم unlockSeconds = -1 لحماية دائمة
  corpse.displayArmor = false إظهار دروع الميت على الجثة (false يُظهر السكين)
  corpse.pose = SLEEPING      وضعية الجثة: SLEEPING أو SWIMMING أو CROUCHING أو STANDING
  hologram.scale = 1.4        حجم الهولوغرام
  hologram.background = "#66000000"  خلفية شفافة (AA RRGGBB)
  hologram.nameColor / despawnColor / protectedColor / unlockedColor
  hologram.height = 1.45      ارتفاع الهولوغرام
  hologram.showName/showDespawn/showProtection = true
  voidRescue.enabled = true   إنقاذ القبر إذا مات اللاعب في الفراغ

【الاستخدام】
- انقر بالزر الأيمن على الجثة لفتح الواجهة.
- زر Take All  = أخذ كل الأغراض إلى حقيبتك.
- زر Restore   = إعادة الأغراض إلى خاناتها الأصلية.
- Shift + زر أيمن = استعادة فورية لكل شيء إلى الخانات الأصلية.
- الضغط على الجثة أو الهولوغرام لا يسمح للآخرين بالفتح قبل انتهاء عداد الحماية.
- الهولوغرام يعرض:
     الاسم (ذهبي)
     Despawns: 59:45   (متى يختفي القبر)
     Protected: 29:45  (متى يُفتح للآخرين) أو Unlocked
- نسبة الخبرة الافتراضية 50%؛ تُعاد عند إفراغ القبر.

【الأوامر】
/corpsegraves list                 قائمة قبورك
/corpsegraves locate               إحداثيات أقرب قبر
/corpsegraves reload               إعادة تحميل الإعدادات (مشرف)
/corpsegraves unlock <player>      فتح كل قبور لاعب (مشرف)
/corpsegraves remove <player>      حذف القبور وإسقاط الأغراض (مشرف)
/corpsegraves open <player>        فتح أقرب قبر للاعب (مشرف/دعم)
/corpsegraves restore <player>     استعادة أقرب قبر للاعب (مشرف/دعم)

【مهم للسيرفرات】
- إذا كنت تستخدم Loader 0.19.5: هذا الإصدار يعمل معه بشرط وجود Fabric API 0.165.0+26.3.
- إذا ظهرت رسالة duplicate mod: احذف النسخة القديمة 1.0.0 من mods.
- بيانات القبور تُحفظ في world/data/corpsegraves_graves.dat وتبقى بعد إعادة تشغيل السيرفر.
- المود لا يستخدم حزماً مخصصة للفانيلا، فلا يكسر اللاعبين غير المودّين.

【إذا لم يعمل شيء】
- تأكد من Java 25 ومن إصدارات Fabric API/Minecraft.
- أرسل آخر 100 سطر من logs/latest.log على السيرفر.
- جرّب /corpsegraves reload ثم اقتل نفسك في عالم اختبار.

إصدار 1.1.0 — تغييرات:
- إصلاح أزرار Take All/Restore (أصبحت أزراراً حقيقية + حزمة أكشن مخصصة).
- إعادة عدّاد الحماية (Despawns + Protected) في الهولوغرام.
- إظهار سكين اللاعب الحقيقي على العميل (حتى سكين TLauncher في وضع offline).
- خبرة 50% افتراضياً، وإخفاء الدروع افتراضياً لإظهار السكين.
- هولوغرام أصغر وأكثر شفافية، و7 خانات تجهيزات، وعرض الخبرة القابلة للاستعادة.
