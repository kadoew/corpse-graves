# NeoForge 1.20.1

This is a legacy NeoForge 47.1.x compatibility target. There is no separate NeoForge 1.20.1 source project: the Forge 1.20.1 jar is binary-compatible with NeoForge's 1.20.1 fork.

Build `forge/1.20.1`, then rename its jar to:

```
corpsegraves-1.1.0+1.20.1-neoforge.jar
```

Verified live on NeoForge 47.1.106 with a vanilla client: grave creation, Interaction hitbox, 3 stacks + 698 XP recovered, grave removed. The same jar is also shipped as the Forge 1.20.1 build.
